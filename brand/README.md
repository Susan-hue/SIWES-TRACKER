# SIWES Outreach brand

| File | Use |
|---|---|
| `logo.svg` / `logo-1024.png` | App mark: rounded brown square, serif "S", sent arrow |
| `logo-maskable.svg` | Full-bleed square for Android/iOS icons (the OS applies its own mask) |
| `logo-wordmark.svg` / `logo-wordmark.png` | Mark plus "SIWES Outreach", for headers, CVs and posts |

The app's icons and favicon (`frontend/public/`) are exported from these files.

## Colours

| Role | Hex |
|---|---|
| Brown (logo, primary buttons, active states) | `#8B4A1F` |
| Brown, hover | `#733C18` |
| Chart brown | `#A0602F` |
| Cream (background, logo letter) | `#F8F5F0` |
| Ink (text) | `#2B2521` |
| Muted text | `#8F8579` |
| Border | `#E8E1D6` |

## Type

- Playfair Display 700: logo letter, wordmark, page titles
- DM Sans: body text and labels
- JetBrains Mono: message drafts
